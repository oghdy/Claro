# 교육부가 수능날 전국 폰에 재난문자 — 짧은 이야기 (옛 꼴 ShortStory)

- 쓴 사람: 로컬 세션 (Sonnet 5.5)이 손으로 썼다 (2026-11-18 15:47 ~ 15:50 · 편집자 · 폰 게이트 지적 두 번 반영 — 마지막 16시 안팎). 모델 API 0 · 파이프라인 명령 0. 골든이 아니다 · 사람 게이트 (폰에서 읽기) 전에는 내지 않는다.
- 재료: 같은 사건 폴더 `store.documents.json` 의 PR-1118-PDF (교육부 · 행정안전부 보도자료) 하나. 언론 기사의 글 · 숫자는 쓰지 않았다.
- 숫자는 아라비아 숫자 (11월 19일 · 8시 30분 · 10.5초간). 말의 셈 "두 가지"는 한글.
- 선반 (series) `exam-fair` 「시험은 어떻게 지켜지나」는 어제 이야기 (suneung-cheating)와 같은 선반 그대로. 어제는 Wi-Fi 차단 (정해진 것 / 검토 요청), 오늘은 재난문자와 수험생 폰 — 겹치지 않는다.
- 어제 게이트에서 배운 것: 큰 제목은 사건이 먼저 (수능날 재난문자) · 물음은 뒤 (가방 속 폰은 괜찮나) · 줄마다 12자 안쪽. `plain.title` 은 답이 아니라 물음 꼴. 쉽게 — 규정 이름 · 기관 말 · 숫자 더미를 덜고 가져갈 것 둘 (대피할 일 아님 · 가방 속 폰도 부정행위).

## 쓰기 전에

1. 세 줄
   - 오늘 뉴스 한 줄: 수능날 (11월 19일) 아침 8시 30분 전국 휴대폰에 위급재난문자 — 교육부 · 행정안전부 (11월 18일)
   - 끌고 갈 물음: 수능날 재난문자가 울리는데, 폰을 안 쓰고 가방에 두기만 해도 괜찮을까
   - 다 읽고 한 문장: 교육부 · 행정안전부가 수능날 보내는 재난문자는 AI 부정행위를 막으려는 조치이고, 수험생은 폰을 쓰지 않았어도 가방 안에 있으면 즉시 부정행위로 처리되니 1교시 전에 감독관에게 내야 한다
2. 독자의 물음 차례 → 장면
   - 누가 왜 수능날 전국 폰에 재난문자를 보내나, 수험생 폰은 → 표지 (cover · 단추 "수험생 폰에는 무슨 일이 생겨요?")
   - 수험생 폰도 울린다 (수신 거부 불가) · 세무사시험 같은 AI 부정행위를 막으려는 조치 · 장관: 전원 끄고 감독관에게 제출 → 무슨 일인가 (where · 뒤집기)
   - 문자를 받으면 어떻게 하나 (모든 국민 · 외국인에게 간다 · 대피 불필요 · 정부의 사전 홍보) → 문서가 말한 것 (why)
   - 한 줄로 → 남음 (keep)
3. 뒤집기 판정 (법 6) — 후보 둘
   - 후보 A (전 국민): "재난문자 = 대피?" — 문서가 막는 말을 1번 한다 (실제 재난이 아니므로 대피 등 별도 조치 불필요). 다만 문자 자체 문구가 (TEST ALERT) · "놀라지 마시고"라 문자를 받는 사람이 실제로 대피한다고 생각할 만한 오해는 약하다고 봤다 → 이 줄기는 뒤집기가 아니라 "문서가 말한 것"에 둔다 (물음 셋째).
   - 후보 B (수험생): "폰을 쓰지 않으면 가방에 둬도 괜찮다" — 문서가 이 오해를 막는 말을 보도자료 부제 · 본문 · 장관 말에서 하지만, 그 막는 말이 "사용하지 않았더라도 … 가방 안에 … 보관 … 즉시 부정행위"의 한 문장 (al05)에 모인다. 독자는 "제출하라"는 말과 "쓰지 않으면 되지"를 쉽게 잇고 (①), 문서의 글자가 깬다 (②). 수험생 · 학부모에게 닿음이 더 크고 내일 아침의 일이라 B 를 골랐다.
   - 선택: B. 까닭: 한 문장에 양쪽 말이 다 있고 ("쓰지 않았더라도" ↔ "가방 안에 보관"), 어제 담화문에만 있어 못 쓴 줄기가 오늘 git 에 둘 수 있는 문서에서 나왔다.
4. 깨는 구절의 키 (meta.json breakers): `al05`. 표지 · 무슨 일인가 본문 · 모르는 것 · 단추 · 첫 생각 · 근거에 달지 않았다 (깨는 사실은 `solve.entry` 의 breaker · flip · note 에만).
   - 오해의 출처 `al07` (전원을 끄고 제출하라)은 깨는 말이 아니라 앞에 둔다.
5. 장면마다 독자가 여기까지 아는 것
   - 표지: 교육부 · 행정안전부가 11월 19일 08시 30분에 전국 폰으로 위급재난문자를 보냄 (이후 추가 예정) · 수험생이 폰을 가방에 두면 괜찮을까 (물음 · 답 없음)
   - 무슨 일인가: 수험생 폰도 받고 거부 못 함 → 세무사시험 같은 AI 부정행위를 막으려는 조치 (문자가 어떻게 가려내는지는 문서에 없음 · 둘을 나란히만 둠) → 장관의 제출 지시 → (첫 생각 "가방에 두면 되겠지") → 깨는 사실 → 뒤집기. 여기서 처음 답이 선다
   - 문서가 말한 것: 모든 국민 · 외국인에게 간다 · 대피 불필요 · 정부의 사전 홍보 (깨는 답 되풀이 없음)
   - 남음: 한 줄 (가방에 있으면 부정행위 · 1교시 전 감독관에게 낸다) + 장관의 확인 당부

## 문서 밖으로 나가지 않은 것 (not_drawn 과 같음)

문자가 숨긴 폰을 어떻게 가려내는지 · 전원을 끈 폰이 가방에 있을 때의 예외 · 2차 이후 발송의 때와 횟수 · 불편 사례 · 다른 시험 — 문서에 없어서 쓰지 않았다. "부정행위를 가려내는 방법" 은 where.unknown 에 문서가 적지 않았다고만 적었다.
