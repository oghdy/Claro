**6. 체험 — 넘겨 보기 5칸**: 사슬 (빼기 차례)을 먼저 따져 봤다. 사슬은 노드 이름 · 멈춘 고리 (reach none)가 누르기 전에 보인다. 이 이야기의 깨는 사실이 바로 “무엇을 빼나” 라서 노드 이름이 답을 말하고, 멈춘 고리 (면제)는 “어디서나 멈춘다”로 읽혀 조건을 잃는다 (8천만원 이하일 때만). 켜고 끄기 · 자리는 안 맞는다. 그래서 넘겨 보기로: 먼저 → 다음 (★) → 그다음 → 또 → 끝으로. 칸의 때 자리 (no_date)에는 날짜 대신 차례 말을 썼다 (법의 셈은 때가 아니라 차례). 뒷면에 보이는 것이 이 말뿐이라 답이 새지 않는다. ★ 앞 물음 “오른 집값이 그대로 부담금의 기준일까요?” = 제목의 물음. 약점: 독자가 거는 것이 ★ 앞 물음 하나뿐이고 화면에 남는 ‘내 것’이 없다 (보이저와 같다) · ★ 뒤에 칸이 셋 더 이어진다.

**7. 시리즈 이름 제안**: 재건축 부담금은 어떻게 매겨요 (code `rebuild` · 부제 “법에 적힌 셈을 한 걸음씩”).
