파이프라인 산출물이 아니다. 로컬 세션 (Sonnet 5.5)이 2026-11-18 에 손으로 쓴 판이다 (모델 API 0 · 파이프라인 명령 0). 편집자 (Opus) 의 빈 곳 목록 · 사람 게이트 (폰에서 읽기) 는 아직 안 거쳤다.

- 시리즈: 새 선반 「AI 해킹은 어떻게 막나」 (`ai-attack`) 의 첫 이야기 (번호 · 시리즈 줄 없음 · 다음 화를 약속하지 않음 — `unpromised`)
- 숫자는 아라비아 숫자 (11월 13일 · 3시간 · 67,000명). 말의 셈은 한글 (쓴 곳 없음)

## 쓰기 전에

### 1. 세 줄
- **오늘 뉴스 한 줄**: FBI 가 11월 13일 경고문을 냈다 — AI 해킹 도구 ARTEX 를 범죄자들이 쓰고 있다
- **끌고 갈 물음**: 그 AI 해킹 도구는 해커가 처음부터 범죄에 쓰려고 만든 걸까
- **다 읽고 한 문장**: FBI 경고문이 말한 ARTEX 는 보안 점검용이라던 AI 도구를 범죄자들이 무기로 삼은 것이고, 만든 사람이 내렸어도 퍼져서 한국 금융기관 피해까지 났다

한 그림: 보안 점검하라고 만든 AI 도우미를 도둑이 가져다 쓴다 (문서의 뜻 — 개발자는 허락받은 보안 시험용이라 했고 FBI 는 범죄자가 무기로 삼았다고 적었다 — 을 넘지 않게 "도둑"은 화면에서 쓰지 않고 "범죄자"로 둠).

### 2. 독자의 물음 차례 → 장면
1. "FBI 가 AI 해킹 도구를 경고했대 — 해커가 만든 거야?" → **표지** (물음 단추: 해커가 만든 도구인가요?)
2. "그래서 그 도구가 뭐 하는 건데?" → **무슨 일인가** 앞 (말로 시키면 AI 가 알아서 · 3시간 · 기술 없는 사람도) → 첫 생각 → 문서의 말 (개발자 · 보안 시험용) → 뒤집기
3. "그럼 만든 사람이 치우면 끝 아니야?" → **문서가 말한 것** (내렸어도 퍼졌다 · 한국 금융기관 약 67,000명)
4. "그럼 어디부터 막아?" → **남음** (FBI 가 기관에 한 당부 · 남는 한 줄 — 개인이 할 일은 문서에 없다)

### 3. 뒤집기 판정
- 오늘 문서가 오해 ("AI 해킹 도구 = 해커가 범죄하려고 만든 것") 를 막는 말을 하는 횟수: 1번 (개발자가 허락받은 보안 시험용이라고 말했다는 한 문장). 반대쪽 말은 많다 (weaponized · malicious · threat actors). 문서 이름이 "Penetration Testing Framework" 라서 이름이 단서를 주지만 화면의 풀이 전 글에는 쓰지 않았다
- 깨는 글자: "The developer stated the tool was intended for authorized security testing within defined scopes" (fl06)
- 세기: **약 ~ 중**. 문서는 개발자의 말을 전했을 뿐 사실로 확인했다고 하지 않고, FBI 도 "무기로 삼았다"까지만 말한다. 그래서 뒤집기를 "처음부터 범죄용으로 만든 도구" ≠ "보안 시험용이라던 도구를 범죄자가 무기로 삼은 것" 으로 좁혔고 (b 에 ‘라던’), 개발자의 말이 맞는지는 쓰지 않았다 (not_drawn). 옛 꼴은 flip 이 틀에서 필수라 약해도 작은 어긋남으로 둠

### 4. 깨는 구절의 키 (meta.json breakers)
`fl06` 하나. 풀이 전의 글 (표지 · 무슨 일 body · unknown · 단추) 에는 이 키도 "보안 시험 · 점검 · 허락받" 도 없다 (ban). `solve.entry.breaker` 에만 달았다. 개발자가 저장소를 내린 문장 (`fl09`) 과 퍼진 문장 (`fl07` · `fl08`) 은 개발자의 "보안 시험용" 말이 없어 풀이 뒤 (문서가 말한 것) 에 두었다

### 5. 장면마다 독자가 여기까지 아는 것

|---|---|---|
| 표지 | FBI 가 11/13 에 AI 해킹 도구 ARTEX 를 범죄자들이 쓴다고 경고했다 | 아니오 — 제목 · 단추가 물음 |
| 무슨 일인가 | + 말로 시키면 AI 가 알아서 명령을 만든다 · 어떤 침입은 3시간 안 · 기술이 적은 사람도 · 피해 총수는 문서에 없다 → (여기서 풀림) 개발자는 보안 시험용이라 했다 | 풀이 앞은 아니오 — plain.title 이 이 장면 머리에 서는 틀 (물음 꼴) |
