## 쓰기 전에

1. 세 줄
   - 오늘 뉴스 한 줄: 수능 시험장 모든 스마트기기 반납 · 공공 Wi-Fi 차단 — 총리 회의 (11월 16일)
   - 끌고 갈 물음: 수능장 Wi-Fi 차단, 정말 막기로 정해진 걸까
   - 다 읽고 한 문장: 총리는 시험장 스마트기기 반납을 지시했지만 Wi-Fi 차단은 방안을 살펴봐 달라고 요청한 단계이고, 시험이 끝난 뒤에도 확인되면 책임을 묻겠다는 방침이다
2. 독자의 물음 차례 → 장면
   - 수능 앞두고 무슨 일이지, Wi-Fi도 막나 → 표지 (cover)
   - 시험장에서는 뭘 하라고 했지, Wi-Fi 는 → 무슨 일인가 (where · 뒤집기)
   - 그럼 정해진 건 뭐고 남은 건 뭐지 (시험 뒤 · 세무사 · TF) → 문서가 말한 것 (why)
   - 시험 보는 사람에게 뭐가 남나 → 남음 (keep)
3. 뒤집기 판정 (법 6)
   - ① 처음 후보 "시험장에서 안 걸리면 끝" ≠ 사후 추적: 보도자료가 그 오해를 막는 말을 부제 하나 + 본문 셋 (이상징후 확인 · 사후에라도 합격 취소 · 세무사 수석합격자 시험 무효)이나 한다 → 오해를 문서가 스스로 막으니 약하다 (기름값은 0번). 버렸다.
   - 대신 이 문서에서 센 어긋남: 부제 "공공 Wi-Fi 차단 등 추진" ≠ 본문 "적극 검토토록 요청하였다" (반납은 "지시"). 독자가 부제만 읽고 "막기로 했다"고 읽기 쉽고 (①), 본문 글자가 깬다 (②). 옛 꼴 (ShortStory)이 뒤집기를 필수로 요구해 (불변식 14) 이 하나를 작은 뒤집기로 썼다 — "정해진 것과 남은 것" 줄기 안이다.
4. 깨는 구절의 키 (meta.json breakers): `pr05` (과기부에 공공 Wi-Fi 차단 방안을 적극 검토토록 요청). 표지 · 무슨 일인가 본문 · 모르는 것 · 단추 · 근거에 달지 않았다. 부제의 "추진" 구절 pr01 은 오해의 출처라 앞에 둔다 (깨는 말이 아니다).
5. 장면마다 독자가 여기까지 아는 것
   - 표지: 11월 16일 총리 회의 · 부제에 반납 · Wi-Fi 차단 "추진" (답 없음 · 제목은 물음)
   - 무슨 일인가 (머리 → 첫 생각 → 깨는 사실 → 반납 지시 → 뒤집기 → 모르는 것): 여기서 처음 답이 선다. 머리 "아직 살펴보는 단계"가 깨는 사실 바로 앞에 선다 (옛 꼴의 차례)
   - 문서가 말한 것: 사후 책임 · 세무사 · TF(가칭) · 법령 개정 검토 — 새 사실, 답 되풀이는 verdict 한 곳
   - 남음: 한 줄 + 신고센터
