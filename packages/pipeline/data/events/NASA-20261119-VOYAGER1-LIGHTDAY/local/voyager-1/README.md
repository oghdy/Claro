# local/voyager-1 — 보이저 1화, 로컬 세션이 쓴 판 (편집자 메우기 3회 거침 · 2026-11-20)

파이프라인 산출물이 아니다. 로컬 세션 (Sonnet 5.5)이 손으로 쓴 판이다 (모델 API 0). 폰 게이트 (PM) 가 한 번 돌려보내 두 번째 메우기를 했다.

- `episode.json` — 계약의 Episode (`episode_version` 1 · 새 시리즈 `voyager` · 체험 = 넘겨 보기 `[pages]` 3칸)
- `screen.json` — 화면 칸: `news` 하나. `burst` 는 두지 않았다 (아래). 사슬이 아니라 `veil` 도 없다
- `meta.json` — `breakers` 셋 (vy.break · vy.confirm · vy.analyze) · `ban` 여섯 · `line`
- 사실 · 숫자 · 구절은 `store.documents.json` 의 NASA 보도자료 (Release 26-098) 한 편뿐이다. 메뉴 글은 쓰지 않았다. 구절은 모두 영어 원문 문장 하나씩 (자르지 않음)

## 쓰기 전에

**1. 세 줄**
- 오늘 뉴스 한 줄: 보이저 1호, 빛으로 하루 거리에 닿았다 (NASA · 11월 19일 발표)
- 끌고 갈 물음: 닿았다는 보이저 1호, 자료는 잘 오고 있을까
- 다 읽고 한 문장: 보이저 1호가 빛으로 하루 거리에 닿았다는 건 신호 (반송파)와 궤도 계산으로 확인한 소식이고, NASA 는 11월 14일부터 과학·공학 자료를 받지 못해 그 문제를 분석하고 있다

**2. 독자의 물음 차례 → 장면**
1. 빛으로 하루가 얼마나 먼 거예요? → 사건
2. ‘빛으로 하루’가 무슨 뜻이에요? → 도구 줍기 (광일)
3. 그런데 보이저 1호는 지금 어떻게 지내요? → 풀이 (넘겨 보기 3칸 → 뒤집기 상자 → 신호는 지금도 와요 · 분석 중)
4. 그럼 지금은 어떻게 이야기해요? → 이어짐 (매일 듣고 주마다 명령 · 신호 시간 · 모르는 것 둘)
5. 그래서 오늘 일을 한 줄로 하면요? → 남음

**3. 뒤집기 — 있음 (중상)**: 오해 “닿았다 = 자료도 잘 온다”. 문서는 중간 한 문단 (vy.break · vy.analyze)에서만 막는다. 겁주는 쪽으로 키우지 않는다 — “분석 중”만큼만 쓴다 (`not_drawn`: 까닭 · 고장 · 전기 · 위험 · 다시 오는 때).

**4. 체험 — 넘겨 보기 3칸**: 11월 18일 닿음 → 24시간 뒤 신호를 들음 → ★ 11월 14일부터 자료는 오지 않았어요 (닿은 건 신호와 궤도 계산으로 확인). ★ 앞 물음 “그 신호에 자료가 실려 왔을까요?” — 제목의 물음 (자료는 잘 오고 있을까)과 ★ 이 푸는 물음이 같다. 깨는 사실은 ★ 에서 처음 나온다. ★ 칸의 때 “11월 14일부터”는 앞 두 칸보다 앞선 날이다 (“그런데 이미 14일부터…” 로 읽히는 자리라 둠 — 차례 검사는 사람 몫). 그림은 칸들 자체 (`picture voyager-path` · 도구 광일).
- 1977 · 2012 칸은 줄기 밖이라 없다 (next.line 에 연표). 켜고 끄기 · 사슬 · 자리는 안 맞아 안 썼다 (사다리 · 사슬 · 자리 이유는 앞 판 그대로: 거리의 차례는 때가 아니다 · 문서가 까닭을 잇지 않았다).
- 약점: 독자가 거는 것이 ★ 앞 물음 하나뿐이고 화면에 남는 ‘내 것’이 없다. 가볍다고 하면 틀이 아니라 체험이 모자란 것이다 (화면 일).
- `burst` 를 안 둔 까닭: 검사 규칙이 구절 글자 그대로 (영어)여야 해서 폰에서 굵은 영어 일곱 줄이 서고 우리말은 작게 따라붙는다. 그래서 끄고 “뒤집어 보면” 상자 (`flip`)가 선다 — 영어 원문은 근거 시트가 이미 띄운다.

**5. 시리즈 이름**: 보이저는 지금 어디쯤 (부제 “빛으로 하루 거리에 있는 탐사선 소식”).

**6. 쓰면서 걸린 것**
- “사람이 만든 것 가운데 처음”은 문서에 없는 말이라 쓰지 않았다 (`not_drawn`). 보도자료의 “historic” · “epic” 같은 감탄 · 개러허의 인용은 싣지 않았다.
- 단위: km 한 군데 (259억 km — 광일). 숫자 근거는 `calc` 로 (“Nov. = 11월”).
- `zero` (0화) 는 1화라 어느 조립에도 안 들어가고 `compare` 는 따라온 독자 조립에만 있다. 둘 다 계약이 글을 요구해 문서 안의 말로만 채웠다.

## 편집자 메우기 2회 (폰 게이트 반려 · 길이 2,995자 → 2,722자)
1. ① **받음** — burst 끔. 구절 글자 그대로라 영어 벽이 되어서. “뒤집어 보면” 상자가 다시 서지만 글은 짧다 (“닿았다” ≠ “자료가 잘 온다” + 한 줄 note).
2. ② **받음** — 넘겨 보기를 3칸으로 다시: 11월 18일 → 24시간 뒤 → ★ 11월 14일부터. ★ 앞 물음을 “그 신호에 자료가 실려 왔을까요?”로. 첫 칸의 깨는 사실이 ★ 으로 옮겨 처음 나온다. ★ 칸 안에 반송파 · 궤도 계산 (vy.confirm).
3. ③ **받음** — 답이 한 곳씩: 깨는 사실 · 확인 = ★ 칸. “신호는 지금도 와요” = real 한 줄 (연락 물음). “분석 중” = verdict 한 번. 반송파 도구 둘째 문장 삭제 · “여기까지” 문구 삭제 · 점선 상자와 안 붙음.
4. ④ **받음** — 사건 단추 · riddle 을 “‘빛으로 하루’가 무슨 뜻이에요?”로 (도구 줍기 첫 문장이 받음). 광일 도구는 259억 km 하나라 가벼운 채로 둔다 (문서에 다른 풀이가 없다).
- 있으면 좋음: 인용 칸 “인류의 우주선 가운데 가장 멀리 날아간 것으로”로 **받음** · 사건 lead 를 인용과 다른 문장 (“49년 넘게 날아 이 거리까지 왔어요”)으로 **받음** · riddle 의 “언뜻 와닿지 않아요” 삭제 **받음** · “넘겨” 반복은 title 과 caption 에만 (label · setup 에서 뺌) **받음** · “이번 주” 삭제 (문서에 없는 말) **받음** · “목요일 이른 때” → “24시간 뒤” **받음** · keep 한 줄을 누가 · 언제 · 무엇이 든 문장으로 **받음** · coming “쌍둥이 보이저” → “보이저” **받음** · 「신호 시간」을 “가는 데 하루, 오는 데 또 하루”로 **받음** · 표지 단추 (“얼마나 먼 거예요”)는 **안 받음** — 물음이 둘 장면 쉬지만 사건이 그 물음을 바로 받는다 · 뼈대 탓은 걸지 않음.
- 그대로: 제목 · 시리즈 · episode_id · code · episode_version 1 · meta.json (breakers · ban 다시 봄 — 풀이 전 글에 없음 · R1 통과).
