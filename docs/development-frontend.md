## F-2b 에 넘길 것 (2026-10-09, F-2a 세션)

기준 구현: **`/lab/b5`** (`apps/web/src/lab/b5/` · 공용 `src/lab/LabSlide.tsx` · `b/b.css` · `b3/b3.css`). 결정은 D26.

**확정 — 그대로 옮긴다**
- 한 번에 한 장. 넘어가는 방법은 물음 버튼 하나. 쓸어서는 안 넘어간다
- 물음 버튼은 다 읽었을 때(버튼 자리가 화면에 들어오고, 앞의 글이 다 나타난 뒤) 나온다. 짧은 장은 화면 아래쪽에 선다
- 누른 물음이 다음 화면의 머리가 된다
- 위쪽 막대 없음. 장수 + 지나온 길(뒤로 가는 길). 안 간 물음은 안 보인다. 마지막 장에 지나온 물음 전부
- 다크 · 고딕(Pretendard — 지금은 CDN, 직접 실어야 한다) · 제목 26 · 본문 16.5 · 물음 버튼 17px. 375×667 에서 입문 4장은 한 번 내려야 한다 — 도윤이 받아들였다(글자를 줄이지 않는다)
- "층" 버튼 = 글자 꼬리표(라벨과 값이 같은 층이면 라벨에만) + 문장을 누르면 설명. callout 은 왼쪽 선
- 움직임 줄이기 설정이면 전환 · 등장 없이 바로

**다시 만든다 — 도윤이 마음에 들어 하지 않았다**
- 넘어가는 동작(물음이 올라가는 모양 · 속도 · 가속감), 글이 나타나는 간격. 지금은 Motion 없이 CSS · Web Animations 로 흉내만 냈고 시간값은 감이다

PM 의 답 (가설): **기사마다 다른 건 체험의 내용이지 종류가 아니다.** 체험의 종류는 몇 개로 모이고, 화면 코드는 틀마다 한 번 만들고, 기사마다 내용(데이터)만 채운다. 파이프라인 = 틀 고르기 (AI 제안 · 사람 1분 승인) + 검증된 사실로 채우기 + 검사. 정말 큰 사건은 손으로 만드는 특별판.
후보 틀 여섯 (PM 이 두 시안에서 뽑은 가설 — **고쳐도 · 합쳐도 · 버려도 된다**):
| 틀 | 체험 | 맞을 것 같은 기사 |
|---|---|---|
| 있을 때 / 없을 때 | 규칙을 켜고 끄며 눌러 보기 | 규제 · 법 · 관세 · 제재 |
| 사슬 | 원인을 밀어 어디까지 닿나 보기 | 금리 · 유가 · 공급망 · 환율 |
| 갈림 | 한쪽 자리에 앉아 그쪽 말 듣기 | 표결 · 정치 · 소송 · 노사 |
| 저울 | 얻는 것 · 잃는 것 올려 보기 | 정책 선택 · 기업 결정 |
| 시간 따라 | 밀어서 전 · 후 넘겨 보기 | 실적 · 지표 · 전쟁 전개 |
| 크기 | 이 숫자가 얼마나 큰지 대 보기 | 과징금 · 예산 · 투자액 |
**이 Step 은 이 가설을 코딩 전에 싸게 확인한다.** 가설을 지지하는 증거만 모으지 마라 — **깨뜨리려고 해 봐라.** 안 맞는 기사가 많으면 그게 이 Step 의 가장 값진 결과다.
