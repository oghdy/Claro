### 만든 방식 — 지시별

- **슬라이드 순서대로, 세로로 한 장씩** — 한 레벨 = `.deck`(scroll-snap-type: y mandatory), 슬라이드 하나 = `.page`(snap start, 최소 화면 높이).
  글이 화면보다 길면 페이지가 늘어난다 — 겹치지 않는다(development-frontend "미리 알아둘 것"의 숙련 4장 12px 겹침: `mobile-advanced-4.png`)
- **레벨 전환 UI** — `levels.length > 1` 일 때만 그린다. 한 레벨이면 없다(테스트 페이지가 한 레벨이라 거기서 확인)
- **open_question = 사이 (D17)** — `Slide` 는 `open_questions` 를 모른다. `Between` 이 `OpenQuestion` 하나를 받아 그린다.
  지금은 `Deck` 이 `[Slide, Between]` 을 한 페이지에 넣는다. 한 화면으로 띄우려면 `Deck` 에서 `Between` 을 자기 `.page` 로 옮기면 된다 — `Slide` · `Between` 은 안 바뀐다.
  형태 기호(Q · ·)는 붙이지 않았다(§5)
- **블록 원형 5개** — 각 컴포넌트는 선형화에 들어가는 필드만 그린다(§7.1-5).
  - prose: `data-weight` 로 무게만 (secondary 작고 흐리게 · callout 테두리 · conclusion 크게). 판단 색 없음
  - list: `ordered` 면 `<ol>` — 번호는 목록이 붙인다. 등간격. `label` 은 글로만 그린다 — 날짜로 읽지 않는다
  - contrast: 두 칸 같은 모양, 위치로만 구분. `emphasized` 는 값 · 글을 굵게(선형화의 `<b>` 와 같은 곳)
  - sheet: 이름 · 값 두 열. 값에 색 없음
  - quote: 출처 표시 + 글
- **모르는 type** — `Fallback` 이 `text` 를 문단 하나로 그린다(`<b>` · `\n` 만). 다른 필드는 읽지 않는다
- **data-layer** — span 마다 `<span data-layer="…">`. 보이는 차이는 없다(F-2)
- **서식** — 글은 전부 React 글자 노드로 넣는다. `dangerouslySetInnerHTML` 없음. `<b>` 와 `\n` 만 `<b>` · `<br>` 로 바꾼다
- **진행 표시** — 장수만큼의 가는 선 + "3/9". open_question 은 세지 않는다(§4). 지금 장 = 화면 가운데를 지난 마지막 페이지(스크롤 위치 → 장 번호, 탐색 계산뿐)
- **마지막 장** — "처음부터 다시 보기" 하나. 피드백 버튼 없음(D18 OPEN)
- **계산 없음 (D12)** — 날짜 · 위치 · 비율을 글에서 뽑지 않는다. `published_at` 도 읽지 않는다
- **판단 색 없음 (D14 규칙 3 · D20)** — CSS 색은 `#1a1a1a` · `#666` · `#ddd` · `#fff` 넷뿐. 뜻에 따라 바뀌는 색 없음
