## ① 도윤이 폰에서 여는 법

**같은 와이파이에서 `http://172.30.1.57:3200/lab/episode`** — 맥에서 `pnpm --filter @claro/web phone` 을 켜 둔 동안 열린다 (빌드 1분쯤. 맥 주소가 바뀌었으면 `ipconfig getifaddr en0`).
- 지금 이 세션이 그 서버를 **켜 둔 채로 끝냈다** (포트 3200). 끄려면 `lsof -ti :3200 | xargs kill`
- 맨 위 검은 줄이 시안 조종 칸이다: **`처음 온 독자` ↔ `따라온 독자`** (누르면 그 독자로 처음부터) · **`근거`** (켜면 근거가 있는 문장에 점선 — 누르면 원문 구절)
- 개발 서버(`next dev`)가 아니라 빌드한 것(`phone`)으로 연다 — 개발 서버는 화면 구석에 Next 표시가 뜨고, 다른 기기에서 열리는지는 확인하지 않았다

```

        │  "이 시리즈가 처음이시네요"                   │  "지난 이야기" 두 줄 (접힌 0화)
        ▼  Q 이 이야기, 어디서 시작됐죠?               │

        2020 요기요 → 2025 전담팀 → 2026.6 동의의결 거절 → 10/29
        ▼  Q 그래서 결론이 어떻게 났죠?  ◀─────────────┘
 3  오늘의 사건 + 끌림 ─ 과징금 둘 (잠정 꼬리표) · 문제가 된 요구 한 문장 · "손님에겐 좋은 얘기 아닌가요?"
        ▼  Q 싸게 팔라는데, 왜 값이 오르죠?
 4  도구 줍기 ─ 중개수수료 · 최혜대우 · 시장지배적 지위
        │  셋 다 "이거 알아요?" → 알아요 = 접힘                │  새 도구 1 (펼침) + 아는 도구 2 (접힘)
        ▼  Q 그래서, 왜 값이 오르는 거죠?
 5  풀이 = "아!" ─ 가게 사장님이 되어 같은 버튼을 두 번 누른다
        요구가 없을 때: 새 앱에서 값 내리기 → 손님이 옮겨 간다

        뒤집어 보면: "비싸게 팔지 마" = "더 싸게 팔지 마"  →  실제로 공정위가 본 것 (13→94% · 63→80% · 90% 넘게)
        ▼  Q 그럼 이 이야기는 끝난 건가요?              ▼  Q 지난번 요기요 때와는 뭐가 다르죠?
                                                 6  견주기 (따라온 독자에게만) ─ 2020 요기요 ↔ 2026: 요구 · 잣대 · 과징금
                                                       ▼  Q 그럼 이 이야기는 끝난 건가요?
 6  이어짐 ─ 시리즈 줄에서 "지금 여기" · 도구 하나 더 ('잠정') · 다음 회차가 될 일 셋 · 아직 모르는 것
        ▼  Q 오늘 내가 얻은 건 뭐죠?
 7  남음 ─ 오늘의 한 줄 · 지도에 새 개념이 붙는다 (알던 것이 먼저 있고 오늘 것이 하나씩) · "다음에 나오면 접어 둘게요" · 다음 화
        └→ 내 개념 지도 (위쪽 줄의 지도 단추로 언제든) ─ 오늘 주움 / 알던 것 / 다음 화에서(점선)
```

각 장의 뜻
| 장 | 의도 | D57 의 무엇 |
|---|---|---|
| 표지 | 한 기사가 아니라 **시리즈의 한 회차**로 들어간다. 제목이 직관과 반대인 물음 | 이어진다 · 맛 |
| 0화 | 과거 기사를 만들지 않고 과거를 한 장으로. 마지막 칸이 오늘로 이어진다 | 이어진다 (런칭의 시작점) |
| 사건 + 끌림 | 사실은 짧게, 수수께끼는 크게. 숫자에는 처음부터 '잠정' 꼬리표 | 맛 · 바닥 |
| 도구 줍기 | **아는 것은 접히고 새것만 펼쳐진다**가 눈에 보이는 자리 | 쌓인다 |
| 풀이 | 설명을 읽는 게 아니라 **독자가 눌러서** 막히는 걸 본다 — "들어가는 느낌" | 맛 |
| 견주기 | 따라온 독자는 개념 설명이 빠진 자리에 **사실이 하나 더** 들어온다 (§8.3) | 쌓인다 · 이어진다 |
| 이어짐 | 끝이 아니라 다음 화가 있다. 모르는 것은 모른다고 | 이어진다 · 바닥 |
| 남음 · 지도 | 읽고 나서 **남은 것이 보인다**. 다음에 접어 주겠다는 약속 | 쌓인다 |

**지시의 순서에서 바꾼 것 둘 — 까닭**
1. **끌림을 표지 제목으로 당기고, 0화를 그 뒤에 뒀다** (지시: 입구 · 0화 → 끌림). 처음 온 독자가 첫 화면에서 연표를 만나면 넘길 까닭이 없다. 제목("싸게 팔라는데, 왜 잘못일까")이 먼저 걸고, 0화는 "이 요구가 6년 전에도 있었다"로 그 물음을 키운 뒤 사건 장에서 수수께끼가 완성된다
2. **'잠정'을 도구 줍기에서 빼서 "이어짐"으로 옮겼다.** 수수께끼를 푸는 데는 필요 없고, "왜 아직 안 끝났나"에서 필요하다. 개념은 쓰이는 자리에서 꺼낸다 — 풀이 앞의 도구가 넷이면 "아!"까지가 멀다 (§1.1: 읽으면 저절로 이해되는가가 먼저)

넘기는 방식은 D26 그대로다 — 한 번에 한 장 · 물음 버튼 하나 · 누른 물음이 다음 장의 머리(`Q …`). 쓸어서 넘기지 않는다.

## ③ 디자인 방향과 까닭 — "따뜻한 종이 위의 먹 글씨, 감색 하나"

| 무엇 | 값 | 까닭 |
|---|---|---|
| 바탕 | 따뜻한 종이 `#F4EEE3` · 면 `#FBF8F1` | "그냥 검은색"에서 벗어난다. 흰색이 아니라 종이색 — 읽을거리라는 느낌 · 눈이 편하다 |
| 글 | 먹색 `#1E1A16` (순검정 아님) | 종이 위에서 대비 14.97:1. 뉴스의 무게는 색이 아니라 **글자의 굵기 · 크기**로 낸다 |
| 강조 하나 | 감색(감 열매) `#CB4821` (흰 글자와 4.68:1) | 따뜻하고 한국 음식 · 장터의 색. 빨강(경고 · 속보)도 파랑(금융 앱)도 아니다. **한 색만** 쓴다 — 여러 색이면 장난감이 된다 |
| 둘째 색 | 이끼색 `#2E6657` — "알던 것 · 접힌 것"에만 | 색이 가르는 것은 **새것 / 알던 것** 하나뿐이다. 옳고 그름 · 좋고 나쁨을 색에 싣지 않았다 (D20) |
| 글꼴 | Pretendard 그대로 · 제목 29px/800 · 표지 35px · 본문 17px/1.72 | 다른 글꼴을 들이지 않았다. 굵기 대비(800 ↔ 400)와 자간으로 표정을 낸다. 본문은 D26 의 16.5 에서 17 로 (밝은 바탕에서는 조금 커도 무겁지 않다) |
| 물음 버튼 | 먹색 면 · 종이색 글 · 아래 화살표 | 본 화면의 "하얀 물음 버튼"을 뒤집은 것 — 화면에서 가장 무거운 것이 물음이다. 화살표는 옆(→ 넘김)이 아니라 **아래(더 안으로)** |
| 그림 | 표지의 두 앱과 **`=`** · 선은 먹 · 채움은 감색 한 번 | `=` 가 이 회차의 그림말이다: 표지 → 풀이에서 두 값을 묶는 고리 → "뒤집어 보면"에 다시 나온다. 글자 · 숫자 없는 그림 |
| 움직임 (Motion) | 장면이 바뀌면 덩이가 0.075초 간격으로 18px 아래에서 올라온다 · 풀이의 손님 점이 스프링으로 옮겨 간다 · 막히면 값표가 내려가려다 되돌아온다 · 지도의 새 개념이 하나씩 붙는다 · 위쪽 지도 단추의 수가 튄다 | 움직임은 **뜻이 있는 자리에만**: 옮겨 감 · 막힘 · 붙음. 팡파레 · 점수 · 레벨 없음. `MotionConfig reducedMotion="user"` — 동작 줄이기면 자리 이동이 전부 꺼지고 바로 바뀐다 (아래 검증) |
| 믿음 | 숫자 옆 '잠정' 점선 꼬리표 · "여기까지는 공정위의 판단" 칸 · `근거` 를 켜면 문장마다 원문 구절 | 장난감처럼 보이지 않게 하는 것은 색이 아니라 **출처가 손 닿는 데 있다**는 것 |

**하지 않은 것**: 경험치 · 레벨 · 배지 · 연속 출석 · 축하 효과. 지도는 "얼마나 아는지"를 그리지 않는다 — 상태는 셋뿐(오늘 주움 · 알던 것 · 아직).
**토큰은 건드리지 않았다.** 값은 전부 `episode.css` 의 `--ep-*` 한 곳에 있다. 도윤이 이 방향을 고르면 그때 `packages/tokens` 로 옮긴다 (_open UX1-a).

## ④ 두 독자에서 무엇이 달라지나 — 같은 회차 · 다른 조립

글은 한 벌이다 (`data.ts`). 독자마다 새로 쓰지 않는다 — **장면을 고르고, 접고, 순서를 바꿀 뿐이다** (D57 "조립").

| | 처음 온 독자 | 따라온 독자 |
|---|---|---|
| 고정값 (`data.ts` `READERS` — **손으로 적었다. 계산하지 않는다**) | 아는 개념 0 · 0화 안 읽음 | 아는 개념 3 (중개수수료 · 최혜대우 · '잠정' 과징금) · 0화 읽음 · 다른 시리즈 개념 2 (예시) |
| 표지 | "이 시리즈가 처음이시네요" → 0화로 | "지난 이야기" 두 줄 → 바로 사건으로 |
| 0화 | **있다** (2장) | 없다 |
| 도구 줍기 | 셋 다 **"이거 알아요?"** — `알아요` 를 누르면 접히고 지도에 "알던 것"으로, `처음 들어요` 면 펼쳐지고 "오늘 주움"으로 | **새 도구 1개가 맨 위에 펼쳐져** 있고, 아는 2개는 아래에 접혀 있다 (`펼치기` 로 언제든) |
| 풀이 | 같다 | 같다 |
| 견주기 (2020 ↔ 2026) | 없다 | **있다** (5장) — 개념 설명이 빠진 자리에 사실이 하나 더 |
| '잠정' 도구 | "이거 알아요?" | 접혀 있다 |
| 남음 | "오늘 새로 주운 개념 n · 원래 알던 개념 m" (누른 대로) | "오늘 새로 주운 개념 1 · 오늘 다시 만난 개념 3" |
| 지도 | 빈 지도에서 시작 → 4개가 붙는다 | 이미 5개가 있는 지도에 1개가 붙고 선 둘이 이어진다 |
| 장수 | 7 | 7 (0화가 빠지고 견주기가 들어온다) |

비교 그림: `logs/frontend/UX-1/new-04-tools-ask.png` ↔ `follower-03-tools.png` · `new-01-cover-b.png` ↔ `follower-01-cover-b.png` · `new-08-map.png` ↔ `follower-08-map.png` · `follower-05-compare.png`

**"이거 알아요?" 는 추정이 아니다.** 독자가 누른 그대로 접는다 — 맞혔는지 재지 않고, 값을 매기지 않고, 저장하지 않는다 (새로고침하면 사라진다). 이것이 관찰 기록에서 무엇이 되는지는 설계하지 않았다 (_open UX1-c).

## ⑤ 문장 고민 · 도윤에게 물을 것

독자가 읽는 글은 전부 `apps/web/src/app/lab/episode/data.ts` 한 파일이다. 고르면 거기만 고친다.

| # | 물음 | 지금 | 고민 |
|---|---|---|---|
| 1 | **시리즈 이름** | 「누가 값을 정하나」 (부제: 플랫폼과 가게, 그리고 규칙) | "플랫폼 규제"는 분류 이름이지 이야기 이름이 아니다. 2020 요기요부터 이번까지 공정위가 문제 삼은 것이 "가게의 가격 결정권"이라 물음꼴로 잡았다. 구글 앱마켓 · 시행령까지 담기에 좁지 않은가 |
| 2 | **제목이 낚시인가** | "싸게 팔라는데, 왜 잘못일까" | 실제 요구는 "싸게 팔라"가 아니라 "다른 앱보다 **비싸게 팔지 마라**"다. 제목은 독자의 첫 인상을 빌렸고, 사건 장에서 바로 정확한 문장이 나오며, 풀이가 그 차이를 뒤집어 보인다. 그래도 제목만 본 사람에게는 부정확하다 |
| 3 | **회차 번호** | 오늘 = 1화 · 그 앞이 0화 | 런칭의 시작점(D57)대로. "0화"라는 말이 어색한가 — "프롤로그" · "지난 이야기" |
| 4 | **풀이의 모형이 사건을 너무 줄였나** | "큰 앱(수수료 높음) ↔ 새 앱(수수료 낮음)" | 공정위 문서의 논리("낮은 수수료로 들어오려는 신규 · 중소 앱의 전략을 무력화")를 그렸다. 실제 사건은 1 · 2위가 서로를 기준으로 삼은 것이기도 하다 (쿠팡이 수수료가 더 높은 후발주자였다). 나중에 더 배우면 **위에 쌓이는** 단순화라고 봤다 (§1.2) — 맞는가 |
| 5 | **회사 쪽 말이 없다** | 풀이 끝에 "여기까지는 공정위가 내린 판단 · 두 회사의 반론은 이 회차에 아직 싣지 않았어요. 양쪽의 공식 입장을 나란히 놓을 수 있을 때 함께 실어요" | 저장된 문서에 쿠팡 입장문은 있고 배민 것은 없다 — 쿠팡 것만 쓰지 않았다 (지시 · D46 ④). 독자는 "회사는 뭐래?"가 궁금하다. (a) 지금처럼 원칙을 말한다 (b) 이 칸을 뺀다 (c) 배민 입장이 나올 때까지 회차를 내지 않는다 |
| 6 | **'잠정'의 까닭을 말하지 못한다** | "아직 확정된 숫자가 아니라는 표시예요 · 최종 금액은 달라질 수 있어요" | 저장된 문서에 왜 잠정인지가 없다 (관련 매출 확정 같은 설명은 내 배경 지식이지 1차가 아니다). 까닭 없이 뜻만 말했다 |
