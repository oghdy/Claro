## 1. C-0010 · `PERSONALIZED_PRICING` — REFRESHER + BOUNDARY

**현재**
- 명제: 개인 데이터로 소비자의 지불 의향을 추정해 사람마다 다른 가격을 제시하는 것. 수급에 따른 가격 변동과는 구분된다.
- FULL (L225): 브라우징 기록, 위치, 구매 이력 같은 개인 데이터로 "이 사람은 얼마까지 낼까"를 추정해서 사람마다 다른 가격을 매기는 것을 말합니다.
- REFRESHER (L228): 개인 데이터로 사람마다 다른 값을 매기는 것입니다.
- BOUNDARY (L231–232):
  > 시장 상황 때문에 **모두에게** 달라지는 가격 → 해당 없음
  > 나에 대한 추정 때문에 **나에게만** 달라지는 가격 → 해당

### BOUNDARY 도 같은 문제인가 — 예, 같은 문제다
- 나이로 매기는 보험료를 넣어 봤다. 보험사는 나이로 **사고 위험**을 추정한다. 이건 "나에 대한 추정"이고 "나에게 달라지는 가격"이라서 BOUNDARY 로는 **해당**이 된다. 명제는 "지불 의향을 추정해"라서 **해당 없음**이다.
- REFRESHER 와 같은 조건, 즉 "무엇을 추정하는가"가 빠져 있다. → 같이 고친다.
- 양화사 "모두에게 / 나에게만"도 확인했다. 수급 변동은 같은 시장에 있는 모두에게 함께 적용된다. 개인화 가격은 나를 보고 매긴 값이다. 두 그림 다 맞으므로 두었다. 이 대비가 BOUNDARY 를 한눈에 읽히게 하는 장치이기도 하다.

**BOUNDARY 수정안** (첫 줄은 그대로 두고 둘째 줄만 바꾼다)
> 시장 상황 때문에 **모두에게** 달라지는 가격 → 해당 없음
> 내가 얼마까지 낼지를 추정해서 **나에게만** 달라지는 가격 → 해당

| | |
|---|---|
| D19 | 나이 보험료 기사: 보험사가 추정하는 건 내가 얼마까지 낼지가 아니라 사고 위험이다 → 해당 없음으로 읽힌다. 명제와 같은 판정 |
| 린트 ① (준용) | "내가 얼마까지 낼지" = FULL "이 사람은 얼마까지 낼까" = 명제 "지불 의향" ✅ S |
| 린트 ② | BOUNDARY 는 스크립트 범위 밖. 손으로 확인: 지시어 없음 |

### REFRESHER 안 A
> 개인 데이터로 "이 사람은 얼마까지 낼까"를 추정해서 사람마다 다른 가격을 매기는 것입니다.

| | |
|---|---|
| D19 | 나이 보험료 기사: 추정하는 게 "얼마까지 낼까"가 아니다 → 해당 없음 ✓ |
| 린트 ① | 개인 데이터로 추정 ✅ S (FULL) · 추정 대상 = 얼마까지 낼까 ✅ S (FULL · 명제) · 사람마다 다른 가격 ✅ S (FULL · 명제). 걸림 0 |
| 린트 ② | 없음 |
| 메모 | FULL 에서 예시 목록(브라우징 기록, 위치, 구매 이력)만 뺀 것이다. 가장 안전하지만 FULL 과 길이가 거의 같고, 문장 안의 인용부호 때문에 한 번에 안 읽힌다 |

### REFRESHER 안 B — 권장
> 내가 얼마까지 낼지를 개인 데이터로 추정해서 매기는 가격입니다.

| | |
|---|---|
| D19 | 나이 보험료 기사: 추정하는 게 내 지불 의향이 아니다 → 해당 없음 ✓. 우버 할증 기사: 나를 보고 매긴 값이 아니다 → 해당 없음 ✓ |
| 린트 ① | 개인 데이터로 추정 ✅ S · 추정 대상 = 내가 얼마까지 낼지 ✅ S (FULL "이 사람은 얼마까지 낼까"를 독자 시점으로) · 그렇게 매기는 가격 ✅ S. "사람마다 다른"은 생략(✅). 이건 정의 조건이 아니라 결과다. 한 사람 한 사람의 지불 의향으로 매기면 사람마다 달라진다. 반례(지불 의향을 추정했는데 모두 같은 값)는 재사용 범위 안에서 나오지 않는다. 걸림 0 |
| 린트 ② | 없음 |
| 메모 | BOUNDARY 둘째 줄과 같은 말("내가 얼마까지 낼지를 추정해서")이라서, 둘이 함께 놓이면 바로 이어진다. 독자 1인칭은 BOUNDARY 의 "나에게만"과 시점을 맞춘 것이다 |

## 2. C-0008 · `POLICY_STATEMENT_VS_RULE` — REFRESHER

**현재** (L193): 이건 방침을 알리는 문서이지 확정된 규칙이 아닙니다.
- 명제: 기관이 내는 문서에는 법적 구속력이 있는 것과 방침을 알리는 것이 있으며, 후자는 그 자체로 의무를 만들지 않는다.
- FULL: F1 기관이 문서를 냈다고 해서 곧바로 규칙이 되는 건 아닙니다. F2 어떤 문서는 "우리는 앞으로 이렇게 볼 것이다"라고 방침을 알리는 것에 가깝고, 그 자체로는 누구도 구속하지 않아요. F3 보통 의견을 받는 기간을 거친 뒤 확정·수정·철회가 결정됩니다.

두 안 모두 "이건"을 없애고 일반형으로 쓴다. 기사 속 문서가 어느 쪽인지는 개념이 아니라 기사가 말할 몫이다.

### 안 A — 권장
> 기관 문서에는 구속력 있는 규칙도 있고, 방침을 알리는 문서도 있습니다. 방침 문서는 그 자체로는 누구도 구속하지 않아요.

| | |
|---|---|
| D19 | 구속력 있는 규칙을 다루는 기사: "구속력 있는 규칙도 있다"가 먼저 나오니 기사 속 문서를 규칙 쪽에 놓을 자리가 있다 ✓. 방침 기사: 둘째 문장이 핵심을 떠올려 준다 ✓ |
| 린트 ① | 구속력 있는 규칙이 있다 ✅ C (명제 "법적 구속력이 있는 것" + F1 "규칙") · 방침을 알리는 문서가 있다 ✅ S (명제 · F2) · 방침 문서는 그 자체로 누구도 구속하지 않는다 ✅ S (F2. "누구도"는 F2 원문에 있는 말). 걸림 0 |
| 린트 ② | 없음 |

### 안 B
> 방침을 알리는 문서는 그 자체로는 누구도 구속하지 않습니다.

| | |
|---|---|
| D19 | 방침 기사 ✓. 규칙 기사에서는 틀린 말은 없다. 하지만 REFRESHER 가 방침 문서 하나만 말하니 독자가 기사 속 문서를 방침 문서에 끼워 맞출 여지가 남는다. D19 가 걱정한 바로 그 방향이다 → 그래서 A 를 권한다 |
| 린트 ① | ✅ S (F2 그대로). 걸림 0 |
| 린트 ② | 없음 |

## 3. C-0005 · `VOTERS_VS_PARTICIPANTS` — FULL

**현재** (L127, v2): 정책 표결은 투표권을 가진 12명이 합니다. 반면 경제 전망은 투표권 여부와 관계없이 회의 참가자들이 **각자** 제출해요. 그래서 "**12대0**으로 결정"과 "**18명 중 9명**이 전망"이 같은 회의에서 나올 수 있습니다.
- 명제: FOMC에서 정책 표결에 참여하는 인원과 경제 전망을 제출하는 참가자 수는 다르다.
- REFRESHER v2 (고치지 않음): 표결은 투표권자 12명이 하고, 전망은 투표권과 관계없이 참가자들이 냅니다. 그래서 두 숫자가 다릅니다.

고치는 방향 (두 안 공통)
- **양화사**: "각자"를 뺀다. B 는 투표권 없는 참가자"도" 낸다고 쓴다. 누가 포함되는지만 말하고 전원이라고는 말하지 않는 방식이다. 의장이 냈는지 안 냈는지도 쓰지 않는다. F20(의장 미제출)이 제도인지 그 회의만의 사정인지는 읽기 범위 안에서 확인할 수 없다. 어느 쪽이든 개념에 넣으면 이번에는 반대 방향으로 시점에 묶인다.
- **숫자**: 실제 회의 값(12대0 · 18 · 9)을 모두 뺀다. 12 는 남긴다. "투표권을 가진 12명"은 표결 인원의 정원이고, 기존 FULL · REFRESHER v2 · D19 어디서도 문제 삼지 않았다(관찰 2).
- **구체성(§4.5)**: 실제 값 대신, 독자가 기사에서 실제로 부딪히는 장면을 예로 둔다. 같은 회의 기사에 숫자가 둘 나오고, 둘 중 하나가 틀린 게 아니라는 장면이다. 운영 노트가 적은 "독자가 반드시 멈춘다"가 바로 그 장면이다.

### 안 A — 최소 수정
> 정책 표결은 투표권을 가진 12명이 합니다. 반면 경제 전망은 투표권과 관계없이 회의 참가자들이 냅니다. 그래서 같은 회의 기사에 표결 인원과 전망 인원이 서로 다른 숫자로 나옵니다. 둘 중 하나가 틀린 게 아니에요.

| | |
|---|---|
| D19 | 의장이 안 낸 회의 기사: "참가자들이 냅니다"는 맨 복수라 예외를 허용한다("새는 난다"와 같다). "각자"가 없으니 "의장은 안 냈다"와 부딪히지 않는다 ✓. 다만 "참가자들이"를 "참가자 모두"로 읽는 독자가 아주 없지는 않다 |
| 린트 ① (REFRESHER v2 ← 새 FULL ∪ 명제) | R1 표결 12명 ✅ S · R2 전망은 투표권과 관계없이 참가자들이 ✅ S (같은 말) · R3 두 숫자가 다르다 ✅ S (3문장 "서로 다른 숫자" · 명제 "다르다") · R4 그래서 ✅ S. 걸림 0 |
| 린트 ② | 없음 |
| 메모 | 첫 두 문장은 "각자 제출해요"만 "냅니다"로 바꿨다(REFRESHER v2 와 같은 말). 셋째·넷째 문장이 실제 값 예시를 대신한다 |

### 안 B — 권장
> FOMC 회의에는 투표권이 있는 사람과 없는 사람이 함께 참가합니다. 정책 표결은 투표권을 가진 12명이 합니다. 경제 전망은 투표권이 없는 참가자도 냅니다. 그래서 같은 회의 기사에 표결 인원과 전망 인원이 서로 다른 숫자로 나와요. 둘 중 하나가 틀린 게 아닙니다.

| | |
|---|---|
| D19 | 의장이 안 낸 회의 기사: "투표권이 없는 참가자도 낸다"는 누가 포함되는지만 말하고 몇 명이 내는지는 말하지 않는다 → 어떤 인원 구성과도 부딪히지 않는다 ✓. 양화사 위험이 A 보다 한 단계 작다 |
| 린트 ① (REFRESHER v2 ← 새 FULL ∪ 명제) | R1 ✅ S (2문장) · R2 "투표권과 관계없이 참가자들이 냅니다" ✅ C (1문장 + 3문장: 투표권 없는 참가자"도" 낸다 = 있는 참가자도 낸다) · R3 ✅ S (4문장) · R4 ✅ S. 걸림 0 |
| 린트 ② | 없음 |
| 메모 | 한 문장에 하나씩(§4.5). 방 안의 그림(투표권 있는 사람 + 없는 사람)을 먼저 주고 표결 → 전망 → 그래서 순으로 간다. 1문장은 새 사실이 아니다. 원래 FULL 의 "투표권 여부와 관계없이 회의 참가자들이"가 이미 전제하던 것을 드러냈을 뿐이다. 약점: 원문보다 두 문장 길다 |

## 4. C-0002 · `INFLATION_LEVEL_VS_RATE` — FULL ④ 를 브리지로

**현재** (L49–63): 헤더 "**FULL** — 반드시 4단계로 나눠 제시한다", 본문 ①②③④, ④ = "**④ 지금 상태** / 목표보다 빠르게 오르고 있어요."

### 안 A — 권장
1. FULL 헤더
   > **FULL** — 개념 3단계(①②③). 기사가 ④ 를 브리지로 붙여 **독자에게는 반드시 4단계로** 제시한다
2. FULL 본문에서 ④ 삭제 (헤더 "④ 지금 상태" + "목표보다 빠르게 오르고 있어요."). **①②③ 은 한 글자도 안 바꾼다.**
3. FULL 본문 뒤에 메모 블록. 빈 줄로 떼어 둔 편집 메모 자리라서 린트 ② 가 보지 않는다.
   > 🔗 **④ 지금 상태 — 브리지 몫. 기사가 붙인다**
   > ③ 바로 다음에, 현재 상승률을 ③ 의 목표와 견주는 한두 문장을 붙인다. 시점이 붙은 사실이라 Concept 에 두지 않는다(§4.3).

4. ANALOGY 🚨 규칙 한 줄
   > 🚨 **이 비유는 ①②③ 과 기사의 ④ 브리지를 먼저 제시한 뒤에만 쓴다.**

## 관찰 — 이번 범위 밖 (고치지 않음)
1. **C-0002 명제 후반부** "상승률이 내려오는 중이어도 목표보다 높을 수 있다"는 FULL ①②③ 어디에도 없다. ④ 가 빠지면 FULL 에 목표와 현재를 견주는 말이 하나도 남지 않는다. 다만 ④ 도 일반형이 아니라 현재 상태를 말하고 있었으므로, 명제 후반부의 자리는 원래부터 비어 있었다.
2. **C-0005 "투표권을 가진 12명"** 은 표결 인원의 정원이다. 이사 자리가 비면 표결 인원이 줄어든다(확인 필요 — 브리프는 읽기 범위 밖). D19 와 REFRESHER v2 모두 12 를 문제 삼지 않아 두었다. aliases "12명 18명"과 운영 노트의 "12와 18"에도 특정 회의 값 18 이 남아 있다. 메타데이터와 편집 메모라서 이번 대상이 아니다.
3. **C-0002 비유 한계선 ①** "속도계는 '2까지 곧 내려간다'는 인상을 준다"는 물가가 목표 위에 있는 국면을 전제한 메모다. 목표 아래인 시기에는 반대 인상("곧 올라간다")이 문제가 된다. 편집 메모라서 린트 ② 가 보지 않는다.
4. **FINDINGS §4.5** "수정본은 `claro-concept-library.md` C-0002 참조" — v3 가 반영되면 라이브러리에는 3단계와 브리지 메모만 남는다. 4단계 전체는 골든 입문 3·4장에서 봐야 한다.
5. **C-0010 aliases 의 법률 용례**(메릴랜드 HB 895, 뉴욕 personalized algorithmic pricing)가 "지불 의향 추정"을 요건으로 하는지는 확인하지 않았다(읽기 범위 밖). 요건이 아니라면, 🚨 dynamic pricing 경고와 같은 "다른 것의 같은 이름" 문제가 하나 더 있는 셈이다.
6. **C-0008 명제의 두 갈래**(구속력 있는 것 / 방침)는 "제안 규칙"이 어느 쪽인지 말하지 않는다. aliases 에 "제안 vs 확정, proposed vs final rule"이 있으니 제안 규칙 기사에도 붙을 것이다. 그때 안 A 의 "구속력 있는 규칙"을 읽은 독자가 아직 확정되지 않은 제안 규칙을 규칙 쪽에 놓을 수 있다. 명제 수준의 문제다. FULL F3 이 그 절차를 조금 말한다.
