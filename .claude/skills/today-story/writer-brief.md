# 쓰는 사람 (Sonnet)에게 넘길 지시 — 틀

`{…}` 를 오늘 것으로 채워 Agent 도구 (model `sonnet`)에 그대로 넘긴다. 채운 것은 하루 기록 ③ 에 먼저 적는다. 틀의 문장은 줄이지 않는다.

---

```
너는 Claro 의 이야기를 쓰는 사람이다. 오늘 ({날짜}) 이야기 한 편을 손으로 쓴다. 모델 API 0 — 파이프라인 명령 (p3 · episode · short …)을 돌리지 않는다.
작업 폴더: {저장소 길} (공개 저장소). 비밀 (키 · .env)을 출력 · 로그 · 커밋하지 마라. 커밋 · push 는 하지 않는다 (부른 세션이 한다).

## 무엇을
- 사건: {사건 code} — {무슨 일 한 줄}
- 무게: {긴 이야기 | 짧은 이야기} · code: {code} · 시리즈: {지금 있는 시리즈 code · 이름 | 새 시리즈 — 이름을 지어 제안}
- 도윤이 고르며 한 말: {그대로 | 없음}
- 고르기 기록: packages/pipeline/data/collect/days/{날짜}-news/sheet.md (왜 이것 · 뒤집기 세기)

## 법 — 먼저 읽는다
1. docs/content/story-guide.md (이야기 짜는 법 — **이 일의 법**. 0 의 잣대가 먼저다: 쉽다 · 구체적 · 오버하지 않는다)
2. logs/frontend/UX-8.md ⑥ (문장 · 이음매) · logs/frontend/UX-9.md ⑤ (체험)
3. docs/contract/EPISODE.md (칸 · 불변식 — 읽기만 · 고치지 않는다)
4. 본보기 — 긴: packages/pipeline/data/events/MOTIR-20261113-OIL-PRICE-CAP/local/oil-1/ (episode.json · screen.json · meta.json · README.md)
   짧은: packages/pipeline/data/events/GPDP-20261114-META-GALLERY/shorts/meta-gallery/story.json (옛 꼴 — 장면 넷: 표지 → 무슨 일 → 문서가 말한 것 → 남음)
읽지 않는다: docs/PM.md · docs/findings/deprecated/

## 재료 — 이것만
- packages/pipeline/data/events/{사건 code}/store.documents.json (1차 문서의 글) · store.json · pack.json
- **사실 · 숫자 · 인용은 이 문서들에 있는 것만.** 언론 기사의 글 · 숫자는 쓰지 않는다. 구절 (quotes)은 문서 글을 **그대로** 뗀다 (키는 네가 짓는다 — 문서 약칭 + 번호). 인용은 자르지 않는다 (문장 하나를 그대로). 기관의 판단은 기관의 말로만.
- 문서에 없으면 쓰지 않는다 — "모르는 것"에 문서가 말하지 않았다고 적는다. 미정인 것을 임의로 정하지 않는다 (못 정하면 돌려줄 때 "막힌 것"에).

## 차례 — 글보다 앞에 적는다 (README.md 의 「쓰기 전에」)
1. 법 1 의 세 줄: 오늘 뉴스 한 줄 · 끌고 갈 물음 · 다 읽고 한 문장
2. 법 2 의 독자의 물음 차례 셋 ~ 다섯 → 장면
3. 법 6 의 뒤집기 판정 (오늘 문서가 그 오해를 막는 말을 몇 번 하나 · 문서의 어느 글자가 깨나). 약하면 뒤집기 없이.
4. **깨는 구절의 키** → meta.json 의 breakers 에 (뒤집기가 없으면 빈 목록). 풀이 전의 글 · 도구 카드 · 근거에는 이 키를 달지 않는다
5. 법 5 의 "장면마다 독자가 여기까지 아는 것" 한 줄씩 — 답이 먼저 보이는 곳이 없는지

## 쓸 것 — packages/pipeline/data/events/{사건 code}/local/{code}/
긴 이야기
- episode.json — 계약의 Episode. 새 이야기면 episode_id 는 새 UUID · episode_version 1. 1화의 처음 온 독자 조립 (assembly.new)에 "지금까지의 이야기" (zero)를 넣지 않는다 (법 4). 체험 틀은 지금 화면에 있는 것만 (사슬 · 켜고 끄기 · 자리 · 넘겨 보기 — 켜고 끄기의 그림은 코드라 새로 못 쓴다). 맞는 틀이 없으면 체험 없이 (기본 풀이) 쓰고 "막힌 것"에
- screen.json — 화면 칸 (계약 밖): news (늘 · 뉴스에서 본 말 그대로 · 폰 한 줄 — 한글 스무 자 안쪽 · 근거 구절 · 숫자는 그 구절에 있는 것만) · veil (사슬 체험의 멈춘 고리 가림) · burst (뒤집기가 있을 때 — 문서의 문장을 구절 이은 글자 그대로)
짧은 이야기
- story.json — 계약의 ShortStory (옛 꼴). 큰 제목은 폰에서 두 줄 안
둘 다
- meta.json — { "breakers": [구절 키…], "ban": [깨는 말의 정규식 — 없어도 됨], "line": { "place": "국내"|"해외", "category": "돈"|"나라와 법"|"기술"|"생활"|"과학과 몸", "unpromised": true|false } }
  unpromised = 다음 화를 약속할 문서가 없으면 true (법 7 — 짐작으로 다음 화를 약속하지 않는다). day 는 적지 않는다 (올리는 세션이 적는다)
- README.md — 누가 (모델) 어떻게 쓴 판인지 · 「쓰기 전에」 (위 1 ~ 5) · 숫자는 아라비아 숫자 (6월 · 12번째 — 말의 셈 "두 번"은 한글)

## 스스로 검사 — 돌려주기 전에
- pnpm --filter @claro/web story:check {사건 code}/{code} → OK 가 날 때까지 (FAIL 을 읽고 고친다 · 경고는 읽고 정한다 — 한글 수가 문서의 수면 숫자로)
- 법의 점검 열하나 가운데 1 ~ 9 · 11 을 예 / 아니오로 (10 — 폰에서 읽기 — 는 부른 세션이 그림으로 한다)

## 돌려줄 것 (글로 — 파일을 더 만들지 않는다)
세 줄 · 장면 차례 한 줄씩 · 깨는 구절 키 · story:check 의 마지막 줄 · 점검 결과 · 시작 – 끝 시각 (date) · 막힌 것 (법이 모자란 곳 · 틀에 안 맞은 곳 · 문서에 없어 못 쓴 것) · 새 시리즈면 이름 안

## 하지 말 것
계약 · 골든 (fixtures) · 지금 나간 이야기 · 이야기 목록 (catalog.tsx) · kit · 소스 팩 · story-guide.md 를 고치지 않는다. 새 색 · 새 그림 없음. 다른 폴더에 파일을 만들지 않는다.
```

## 메우기 — 편집자 목록을 돌려줄 때 (⑤ · 같은 서브에이전트에 이어서)

```
편집자가 네 글의 빈 곳을 짚었다 (아래). 고쳐 쓴 문장은 없다 — 받을지, 어떻게 메울지는 네가 정한다.
- 항목마다 **받음 / 조금 / 안 받음 + 까닭 한 줄**. 편집자도 법 맞춤을 무겁게 볼 수 있다 — 읽는 맛 (쉽다 · 구체 · 오버 안 함)이 무거워지면 받지 않는다.
- 받은 것은 **네 말로** 메운다. 문서에 있는 것으로만. 새 장면을 만들지 않는다. 남의 말은 한 문장에 하나.
- **길이는 그대로이거나 짧게** — story:check 의 "길이" 줄을 앞 · 뒤로 적는다.
- 구절을 더하거나 바꿨으면 깨는 구절 키 (meta.json breakers)도 다시 본다.
- 끝나면 story:check OK → 돌려줄 것: 항목마다 정함 + 까닭 · 바뀐 글 앞 → 뒤 (칸 이름과 함께) · 길이 앞 → 뒤 · 걸린 시간.

{편집자의 빈 곳 목록 그대로}
{게이트 · 도윤이 더 짚은 것이 있으면 그대로}
```
