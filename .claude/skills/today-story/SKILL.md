# 오늘 이야기 만들기

도윤이 아침에 한마디 하면 이 차례대로 일한다. **사람이 정할 곳 (멈춤 둘)에서만 멈추고**, 나머지는 혼자 끝까지 간다.
법은 `docs/content/story-guide.md` (이야기 짜는 법 v2) 하나다 — 이 스킬은 차례 · 도구 · 멈춤만 정한다. 법과 부딪히면 법이, 법과 읽는 맛이 부딪히면 **읽는 맛**이 이긴다 (쉽다 · 구체적 · 오버하지 않는다 — D119).

## 한눈에

| | 무엇 | 누가 | 나오는 것 |
|---|---|---|---|
| ① | 고르기 — 오늘의 큰 뉴스 → 1차 문서 → 권리 → 국내 1 · 해외 1 | 이 세션 | `days/<날짜>-news/sheet.md` · `picks.json` |
| **멈춤 1** | **도윤이 고른다** (무엇을 · 긴 / 짧은) | 도윤 | |
| ② | 원문 · 소스 팩 (모델 없이) | 이 세션 | `events/<사건>/` (`pack.json` → `store*.json`) |
| ③ | 쓰기 | **Sonnet** 서브에이전트 | `events/<사건>/local/<code>/` |
| ④ | 빈 곳 짚기 (고쳐 쓰지 않는다) | **Opus** 서브에이전트 | 빈 곳 목록 (하루 기록에) |
| ⑤ | 메우기 (받음 / 조금 / 안 받음 + 까닭) | **Sonnet** (③ 의 그 서브에이전트) | 같은 폴더 |

길: `packages/pipeline/data/collect/days/` · `packages/pipeline/data/events/`. 날짜는 한국 날짜 (`TZ=Asia/Seoul date +%F`).

## 시작할 때

1. `CLAUDE.md` · `docs/content/story-guide.md` 를 읽는다. `docs/PM.md` · `docs/findings/deprecated/` 는 읽지 않는다.
2. `pnpm install` · `git status` (남의 미커밋을 본다 — 건드리지 않는다) · `python3 scripts/verify-ledger.py` 의 **합을 적어 둔다** (끝에 같아야 한다).
3. `logs/today/<날짜>.md` 를 만들고 시작 시각을 적는다 (`date`). **일하면서 채운다** — 끝에 몰아 쓰지 않는다.

## ① 고르기

본보기: `logs/pipeline/S-3.md` · `days/2026-11-15-news/` (`sheet.md` · `picks.json` 의 꼴 그대로).

- **뉴스에서 출발한다** (D107) — 오늘 국내 · 해외에서 크게 다룬 일 다섯씩 (머리기사 묶음에서 "몇 곳이 썼나"로 어림). 그다음 그 일의 **1차 문서** (발표문 · 고시 · 결정문 · 통계)를 찾아 **실제로 열어 본다**.
- 후보마다: 무슨 일 · 1차 문서 주소 · 권리 (`packages/pipeline/src/rights.ts` 의 갈래) · 열어 봤나 · 닿음 (누구의 일인가) · **뒤집기 세기** (법 6 — 오늘 문서가 그 오해를 막는 말을 하는지 **센다** · 문서의 글자가 깨나). 약하면 뒤집기 없는 이야기로 선다고 적는다.
- 제안: **국내 1 · 해외 1** · 무게 (긴 / 짧은)와 까닭 · 고르지 않은 큰 것과 까닭 (1차 문서가 아직 없다 · 권리 …).
- **언론 기사의 본문 · 첫 문단은 git 에 넣지 않는다** — 제목은 내 말로 · 언론사 · 주소 · 요지만. **언론이 쓴 숫자는 적지도 쓰지도 않는다** (D108 — 1차에서 본 것만).
- 1차 문서가 없는 큰 뉴스는 고르지 않는다 (기다림) — 개념 이야기로 설 수 있으면 그렇게 적는다.

### 멈춤 1 — 도윤에게 (결론 먼저 · 쉬운 말 · 표 하나)

국내 · 해외 한 줄씩: **무슨 일 · 왜 이것 · 긴 / 짧은 · 끌고 갈 물음 한 줄 · 걸리는 것** (권리 · 새 시리즈라 표지 그림이 필요 …). 고르지 않은 큰 뉴스도 한 줄. → **도윤의 답을 기다린다.** 하루 몇 편인지는 도윤이 정한다 (정해진 수가 없다 — 아래 "아직 정하지 않은 것").

## ② 원문 · 소스 팩 — 모델 없이

- 사건 code = `<기관>-<발표일 YYYYMMDD>-<짧은 이름>` (예 `MOTIR-20261113-OIL-PRICE-CAP`). 이야기 code = 긴: `<시리즈>-<번호>` (`oil-1`) · 짧은: 짧은 이름 (`meta-gallery`) — 실제 주소가 된다 · 한 번 나가면 바꾸지 않는다.
- 사건 폴더 `events/<사건 code>/` 에 `pack.json` 을 손으로 쓴다 (본보기 `events/MOTIR-20261113-OIL-PRICE-CAP/pack.json` — 무엇 · 누가 · 주소 · 왜 · 주소를 어떻게 확인했나 · 공개 시각과 그 증거 글). 주소는 **실제로 열어 확인한 것만**.
- `pnpm --filter @claro/pipeline p2 <사건 code>` (받기 · 뽑기 · 해시 — robots 가 막으면 받지 않는다 · 우회하지 않는다) → `python3 scripts/verify-source-pack.py` OK.
- **권리** (D70 · D92 · D109): git 에 전문을 두는 것은 `rights.ts` 의 갈래뿐 (미 연방 · 공공누리 제1유형 · 한국 법령 · 기관이 밝힌 "출처 밝히고 바꾸지 않으면" 허락). 발행처는 미확인이어도 **문서 안에** 공공누리 제1유형 표시가 있으면 그 문서만 git — 그림을 **눈으로 보고** `doc_rights` 에 본 자리 · 해시를 적는다. 그 밖은 **미확인 = 캐시에만** (`packages/pipeline/.cache/` — git 밖).
- **이야기의 근거는 git 에 둔 문서 (`store.documents.json`)의 글자뿐이다.** 캐시의 글은 읽어 배경으로만 삼고 구절로 쓰지 않는다 (검사가 막는다). 꼭 필요한 문서가 미확인이면 → 새 권리 갈래가 필요한 일이다: **멈추고 도윤에게** (`docs/DECISIONS.md` 에 OPEN).
- `p3` · `p4` · `p5` · `episode` · `short` · `short-flow` · `w2` · `w6` · `rerun` · `collect` · `recommend` 는 **돌리지 않는다** (모델 API). 구절은 쓰는 사람이 저장된 문서에서 바로 뗀다.

## ③ 쓰기 — Sonnet 서브에이전트

`writer-brief.md` 의 틀에 오늘 것 (사건 · code · 무게 · 도윤이 고르며 한 말)을 채워 **Agent 도구 · model `sonnet`** 으로 띄운다. 채운 지시문은 **하루 기록에 먼저 적는다**.
나오는 것 — `events/<사건>/local/<code>/`:

| | 긴 이야기 | 짧은 이야기 (옛 꼴 — 장면 넷 · D104) |
|---|---|---|
| 글 | `episode.json` (계약 Episode) | `story.json` (계약 ShortStory) |
| 화면 칸 | `screen.json` (`news` 늘 · `veil` · `burst` — 법 「화면 칸 셋」) | 없음 |
| 손 칸 | `meta.json` — `breakers` (깨는 구절 키 · **쓰기 전에**) · `ban` (깨는 말 · 없어도 됨) · `line` (`day` · `place` · `category` · `unpromised`) | `meta.json` — `line` (+ `breakers` 는 적으면 본다) |
| 한 장 | `README.md` | `README.md` |

두 편이면 서브에이전트 둘을 나란히 띄운다 (폴더가 다르다).

## ④ 빈 곳 — Opus 서브에이전트 · ⑤ 메우기 — Sonnet

- ④ `editor-brief.md` 로 **Agent 도구 · model `opus`**. 편집자는 **목록만** 낸다 (다섯 개 안쪽 · 다섯 물음 · 문장을 지어 주지 않는다 · 파일을 고치지 않는다). 목록을 하루 기록에 붙인다.
- ⑤ 그 목록을 ③ 의 서브에이전트에게 돌려준다 (`writer-brief.md` 의 「메우기」 — SendMessage 로 이어서 · 없으면 새 Sonnet 에 글 + 목록). 항목마다 **받음 / 조금 / 안 받음 + 까닭** → 제 말로 메운다 → 길이는 그대로이거나 짧게. 이 세션이 글을 대신 고치지 않는다.
- 짧은 이야기도 같은 차례를 밟는다 (편집자 목록은 셋 안쪽).

## ⑥ 코드 검사 — 한 명령

```
pnpm --filter @claro/web story:check <사건>/<code>
```
계약 (저장된 문서로 구절 · 숫자 대조) · 화면 칸 (실제 화면의 검사와 같은 함수) · 깨는 구절이 풀이 전 글 · 도구 · 근거에 없는지 · `meta.json` 의 꼴. **FAIL 은 쓰는 사람에게 돌려보낸다** (이 세션이 글을 고치지 않는다 — 키 오타 같은 글 아닌 것만 고친다). **경고**는 읽고 정한다: 한글 수 (말의 셈이면 둔다) · 뉴스 한 줄 길이 · 큰 제목 줄 · 1화의 "지금까지". 결과를 하루 기록에 **붙인다**.

## ⑦ 미리 보기 — 폰 그림 → 게이트 → lab 주소

1. 폰 그림 (390×844 · 장면마다 · 빌드하고 서버를 띄웠다 끈다 — 약 1분):
   ```
   pnpm --filter @claro/web story:shots <사건>/<code>
   ```
   → `apps/web/.data/shots/<code>/` (git 밖). 찍힌 줄 (뉴스 한 줄 · 큰 제목이 몇 줄 · 가로 넘침 · 콘솔 오류)을 본다.
2. **그림을 처음부터 끝까지 읽는다** (Read 로 한 장씩) — `gate.md` 의 점검 열하나. 화면 · 그림 판단은 Fable 이 한다 (이 세션이 Fable 이 아니면 Agent 도구 · model `fable` 에 그림 폴더와 `gate.md` 를 준다). 걸리면: 글 → 쓰는 사람에게 (⑤ 처럼) · 화면 틀 → 고치지 말고 "걸린 것"에 적는다.
3. 통과하면 **그 이야기의 파일만** 커밋 · push (`git add <파일>` 하나씩 · `git commit -m "today <날짜> <code> 미리 보기" -- <파일들>` — 매일의 커밋 접두사는 Step 이름 대신 `today <날짜>`): `local/<code>/*` · 사건 폴더의 팩 파일 · `days/<날짜>-news/*` · 하루 기록. push = 배포 — **lab 주소만 생긴다 · 실제 화면 0 변화** (목록에 줄을 적지 않았다).
4. 배포를 기다려 (1 ~ 2분) `curl -s -o /dev/null -w "%{http_code}" https://claro-lime-one.vercel.app/lab/local/<사건>/<code>` → 200.

## 지킬 것

- **모델 API 0.** 파이프라인의 모델 명령을 돌리지 않는다 (② 의 목록). 끝에 장부 합이 그대로다.
- **비밀 (키 · .env)을 출력 · 로그 · 커밋하지 마라.**
- **git**: `git add -A` · `git add .` 금지 — 파일을 하나씩. 커밋도 파일 지정 (`git commit -m "…" -- <파일들>`). `git stash` · `pull --rebase --autostash` · `checkout -- <폴더>` · `reset --hard` 금지. push 가 거절되면 `git pull --no-rebase`. 커밋 전 `git status` 로 남의 미커밋을 보고 건드리지 않는다. `.claude/launch.json` 은 건드리지 않는다.
- **공개 저장소다.** 권리 미확인 원문 · 언론 기사 본문은 git 에 없다. 폰 그림은 git 에 넣지 않는다 (`apps/web/.data/` — 날마다 수십 장이라).
- **근거**: 사실 · 숫자 · 인용은 이 사건의 저장된 문서에 있는 것만. 언론의 숫자 금지 (D108). 인용은 자르지 않는다. 기관의 판단은 기관의 말로.
- **모델**: 글 = Sonnet · 편집자 = Opus · 그림 · 화면 판단 = Fable. 이 세션은 글을 쓰지도 고치지도 않는다 (차례 · 검사 · 게이트 · 올리기).
- **건드리지 않는 것**: 계약 (`docs/contract/*`) · 골든 (`fixtures/*`) · 지금 나간 이야기의 글 · 목록의 지금 줄 · kit (화면 뼈대) · `docs/content/story-guide.md`. 고치고 싶은 것은 하루 기록의 "걸린 것"에.
- **미정 항목을 마주치면 임의로 정하지 않는다** — `docs/DECISIONS.md` 에 OPEN 으로 올리고 멈춘다. CLAUDE.md 의 "절대 하지 말 것"은 여기서도 그대로다.
- **도윤에게**: 한국어 · 결론 먼저 · 쉬운 말 · 숫자는 아라비아 숫자. 폰에서 읽는다 — 긴 표 · 파일 길 나열은 하루 기록에.
- 띄운 서버 · 백그라운드 일은 끝날 때 다 끈다 (`story:shots` 는 스스로 끈다).

## 아직 정하지 않은 것 (마주치면 정하지 말고 도윤에게)

- **구독 요금제로 상업 서비스의 글을 쓰는 조건** (D110) — 약관 확인 전이다. 사람이 시키고 보고 올리는 지금 꼴만 한다. 스스로 도는 꼴 (예약 · 반복)로 만들지 않는다.
- **화면 칸 (`screen.json`) · `meta.json` 을 계약으로 올릴지** — 지금은 계약 밖 손 칸이다 (D125 · D126 e). 칸을 늘리지 않는다.
- **하루 몇 편** — 정해진 수가 없다. 멈춤 1 에서 도윤이 정한다 (지금까지는 국내 1 · 해외 1 = 긴 1 · 짧은 1).
- **새 시리즈의 표지 그림** — 기본 그림으로 올리고 묻는다. 누가 · 언제 그릴지 정해지지 않았다.
- **e2e 가 그날 묶음에 묶여 있다** — 새 이야기를 올릴 때마다 `episode.spec.ts` · `today.spec.ts` 의 값을 맞춰야 한다 (⑧ 2). 목록에서 읽게 고칠지는 프론트 Step 의 일이다.
- **같은 시리즈의 다음 화 (2화 ~)** — "지금까지의 이야기" · 지난 값 · 번호 화면이 걸린다. 로컬 세션으로 2화를 써 본 적이 없다 — 첫 번째는 멈춤 1 에서 그렇다고 말한다.
- **뒤집기 없는 긴 이야기 · 사슬이 아닌 체험 틀** — 검사는 받지만 로컬 세션으로 써 본 실물이 기름값 1화 (사슬 · 뒤집기) 하나다.
